# 🏰 Крепость — стратегия в духе Stronghold для Android

Градостроительная стратегия: стройте замок, кормите народ, собирайте налоги и отбивайте набеги.
Игра — HTML5-приложение (`app/src/main/assets/www/index.html`), запакованное в Android WebView.
Работает полностью офлайн, без рекламы и внешних зависимостей.

## Как собрать APK

### Способ 1. Облачная сборка на GitHub (ничего устанавливать не нужно)
1. Создайте новый репозиторий на github.com и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
3. Через 2–4 минуты скачайте `Stronghold-apk` из раздела *Artifacts* — внутри `Stronghold.apk`.

### Способ 2. Android Studio
**File → Open** → выберите эту папку → дождитесь синхронизации Gradle →
**Build → Build Bundle(s) / APK(s) → Build APK(s)**.
Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

### Способ 3. Командная строка
Нужны JDK 17+ и Android SDK:

```bash
./build_apk.sh
```

Результат — `Stronghold.apk` в корне проекта.

## Установка на телефон
Скопируйте APK на телефон и откройте его. Если Android попросит, разрешите установку из неизвестных источников.
APK подписан отладочным ключом — для личной установки этого достаточно. Для публикации в Google Play
подпишите своим ключом.

## Проверка в браузере
Игру можно открыть без сборки: просто откройте `app/src/main/assets/www/index.html` в Chrome
(на телефоне или компьютере). Сохранения хранятся в `localStorage`.

## Правила игры
- 🏠 **Хижины** дают жильё. Крестьяне приходят, пока есть места и народ доволен (популярность ≥ 40%).
- 🪓 **Лесоруб** ставьте рядом с лесом, ⛏️ **каменоломню** — рядом со скалами (штриховой круг показывает радиус добычи), 🌾 **фермы** кормят народ. Каждому зданию нужны рабочие.
- ⚖️ **Казна**: налоги и рацион. Больше налогов — больше золота, но ниже популярность. ⛪ Церкви поднимают популярность.
- ⚔️ Враги приходят **волнами** (первая — на 14-й день). Они ломают то, что мешает пройти, — стены задерживают их под огнём башен.
- 🗼 **Башня** стреляет, пока в ней работает крестьянин. ⚔️ **Казарма**: тап по ней → «Нанять» (5 воинов на казарму).
- 🏆 Отбейте 12 волн и не дайте разрушить донжон.

## Управление
Тап — построить или выбрать здание · перетаскивание — двигать карту · щипок — масштаб ·
стену рисуйте пальцем (карту при этом двигайте двумя пальцами) · кнопка ▶ — скорость 1×/2×/3×/пауза.
На компьютере: WASD/стрелки, колесо мыши, пробел — пауза, цифры 1–8 — выбор постройки.

## Структура
```
app/src/main/assets/www/index.html   ← вся игра
app/src/main/java/.../MainActivity   ← WebView-оболочка (полный экран, ландшафт, кнопка «Назад»)
.github/workflows/build-apk.yml      ← облачная сборка APK
```
